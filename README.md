## Hello, I'm Leon.

I'm interested in how software becomes useful in the physical world: understanding a request, interpreting sensor data, taking an action and checking what actually happened.

At UWA, I study a **Bachelor of Engineering (Honours) and Bachelor of Commerce**, majoring in **Software Engineering and Finance**. My 2026 Software Engineering thesis research is **OpenBot for the Unitree G1**. Alongside that, I work on computer vision, backend applications and cloud deployment.

I'm looking for internships where I can contribute in software and learn more about robotics integration, perception and testing alongside people who build real systems.

## Selected work

### 01 / OpenBot for Unitree G1
**Embodied AI · Software Engineering thesis research · 2026**

A research prototype connecting spoken requests and LLM tool calls to robot navigation, manipulation and stop skills.

- Connected a language-driven planner to deterministic robot skills through a tool gateway.
- Worked with state checks, bounded timeouts and measured completion or refusal outcomes.
- Used simulation alongside hardware trials to investigate integration and failure cases.

`Python` `ROS 2` `MuJoCo` `Robot integration`

[Explore the research →](https://github.com/enqinghayashi/OpenBot-UnitreeG1)

### 02 / Street Number Recognition
**Computer vision · Detection + recognition**

A two-stage pipeline that detects individual digits with YOLO, classifies the crops with EfficientNet-B0 and reconstructs numbers from left to right. The repository also includes an alternative multi-head recognition baseline.

`Python` `PyTorch` `YOLO` `EfficientNet`

[Explore the project →](https://github.com/enqinghayashi/Street_Sign_Detector)

### 03 / Rankd
**Backend engineering · University team project + cloud deployment**

A music rating application comparing user ratings with listening history. My contributions covered **Flask features, database functionality, testing, Docker and AWS deployment**.

The deployment work used ECS Fargate, an Application Load Balancer and PostgreSQL on RDS. The repository documents the original team phase and the later cloud deployment phase; the historical public deployment is no longer maintained.

`Flask` `SQLAlchemy` `PostgreSQL` `Docker` `AWS`

[Explore the application →](https://github.com/enqinghayashi/Rankd-Music_Rating_AWS)

### 04 / Mini Bitcoin Blockchain
**Systems exploration · Educational Go project**

An educational blockchain implementation exploring proof-of-work, UTXO transactions, digital signatures, persistence and local peer-to-peer synchronisation.

`Go` `ECDSA` `BoltDB` `TCP`

[Explore the implementation →](https://github.com/enqinghayashi/Bitcoin_miniBlockchain)

## How I use AI

I write **role-specific prompts** to coordinate AI agents on coding and problem-solving tasks, with defined responsibilities and instructions to report bugs they cannot resolve. I let agents work autonomously within the task scope and bring unresolved decisions back to me.

The part I find most interesting is the orchestration itself: how to divide work, provide enough context and make progress and blockers visible. This is a personal workflow I continue to develop.
